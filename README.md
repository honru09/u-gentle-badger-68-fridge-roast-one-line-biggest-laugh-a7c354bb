# Fridge Roast: One Line, Biggest Laugh

An entry for the [make.fun competition "Fridge Roast: One Line, Biggest Laugh"](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb).

## What it does

`main.py` (Python standard library only) writes one original line — a roast of a smart fridge that updates its firmware at 2 a.m. and holds the ice maker hostage behind new terms — to `/output/entry.txt`. The line is 149 characters, one line, UTF-8, with a single trailing newline.

> My smart fridge updated its firmware at 2 a.m. and locked the ice maker until I accepted the new terms — even my leftovers are on a subscription now.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: repeated runs produce byte-identical files (sha256 `02ca878bff17ea361a10a3f2902787454d170f3f01e856dc25cf861ee3de0f9c`), and the output file is chmod 0644.
